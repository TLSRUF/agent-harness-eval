- 관찰: 정상 종료율(error_max_turns가 아닌 실행) max_turns default 100% (120/120), max_turns 3 34% (41/120), max_turns 4 72% (86/120), max_turns 5 92% (111/120), max_turns 7 100% (120/120).

- 가설: 작은 max_turns에서 성공률이 정상 종료율보다 훨씬 높은 것은 에이전트가 한계에 걸리기 전에 이미 결과 파일을 써 두기 때문이다(채점 통과 건수 행 참고).
- 가설: 한계 판정 규칙은 응답 수 > max_turns일 때 중단(max_turns 3, 4, 5에서 일치, 가설 수준).

### 한계

- error_max_turns로 끝났지만 파일 결과가 채점을 통과한 실행이 있어 성공률과 정상 종료율은 다른 지표다.
- 한계 규칙(응답 수가 max_turns를 넘으려 할 때 중단)은 max_turns 3, 4, 5에서만 확인했고 7과 20은 확인 불가(한계에 걸린 실행이 없다).
- 과제당 3회.
