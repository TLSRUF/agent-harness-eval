# Runbook
Last updated: 2026-03-14
Disk usage is checked by the nightly job.
By default the server uses port 9000.
Metrics are sent every minute.
Check the service logs before restarting.
Rotate credentials every quarter.
Review alerts at the start of each shift.
Restart the worker after changing the schedule.
Contact the on-call engineer for urgent issues.
Document every change in the team notes.
Backups run every night at low traffic.
Escalate unknown errors to the platform team.
Use the staging environment for dry runs.
