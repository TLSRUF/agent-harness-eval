# 실험 D 비교표 (exp_compare)

- 비교 범위: 같은 (과제, run) 쌍 40건, 과제 40개(E01, E02, E03, E04, E05, E06, E07, E08, E09, E10, E11, E12, E13, E14, E15, H01, H02, H03, H04, H05, H06, H07, H08, M01, M02, M03, M04, M05, M06, M07, M08, M09, M10, M11, M12, M13, M14, M15, M16, M17). haiku baseline 전체 120건 중 40건, sonnet 전체 40건 중 40건을 비교한다(나머지는 제외).
- 입력: 최종 실행 로그만 읽는다(.partial, _final 제외). 읽기 전용, 모델 호출 없음. 도구 설명 default, 프롬프트 v1, max_turns 20으로 같다.
- 일관성은 같은 과제의 반복이 2회 이상인 쌍에서만 계산되어, 과제당 1회 시험이면 n/a다.
